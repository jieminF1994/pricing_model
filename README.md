# Pricing Model

This repository contains pricing model source files and assumption inputs.

## Contents

- `pricing_faia/` - Fixed indexed annuity model sources and assumptions.
- `pricing_rila/` - RILA model sources, assumptions, data, and scenarios.

## Notes

- Excel assumption workbooks and CSV inputs are versioned with the model code.
- Local editor settings, macOS metadata, temporary Excel lock files, and C/C++ build outputs are ignored.
